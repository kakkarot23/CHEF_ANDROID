# CHEF_ANDROID (CHEF App)

A modern Flutter application for chefs and food enthusiasts.

## Features
- **Home Feed**: Discover trending culinary posts and chef creations.
- **Short Videos**: Engage with short cooking clips and recipe showcases.
- **AI Recipe Generator**: Instant AI-powered recipe generation and ingredient suggestions.
- **Chef Profile & Portfolio**: Manage recipes, posts, and saved favorites.
